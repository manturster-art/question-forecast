# 별칭.json 쓰는 법

`config/별칭.json` 은 결과보고서·세출 자료에 나오는 **옛 이름·줄여 쓴 이름 → 현재 정식 부서 이름** 표입니다.
들어 있는 세 줄은 모양을 보이기 위한 예시입니다(가상 지자체 「가나시」). 자기 지자체 자료로 바꿔 넣으십시오.

```json
{ "행정복지센터": "동행정복지센터", "도시공사": "가나도시공사", "녹지과": "정원도시과" }
```

## 넣는 기준

- 자료로 까닭을 댈 수 있는 것만 넣고, 줄마다 근거를 이 파일에 표로 적어 둡니다.
  - 부서 개편: 시 세출 자료에서 옛 부서의 마지막 해 사업 가운데 과반이 다음 해 한 부서로 옮겨 갔는지 셉니다.
  - 기관 개칭: 결과보고서의 같은 자리(묶음 머리)에 해마다 어떤 이름이 나왔는지 봅니다.
  - 같은 것을 가리키는 두 꼴(「동 행정복지센터」·「행정복지센터」)은 다수 꼴로 모읍니다.
- 한 옛 부서가 여러 새 부서로 갈렸으면 넣지 않습니다. 한 이름으로 몰면 틀린 이력이 생기므로 옛 이름 그대로 두면
  화면에서 「현재 조직도에 없음(current=false)」으로 보입니다.
- 넣은 뒤 `python run.py --offline` 으로 다시 굽고, 부서 목록에 같은 부서가 두 번 나오지 않는지 봅니다.

| 옛 이름 | 새 이름 | 근거 |
|---|---|---|
| 행정복지센터 | 동행정복지센터 | (예시) 같은 것을 가리키는 두 꼴 |
| 도시공사 | 가나도시공사 | (예시) 결과보고서 묶음 머리에서 줄여 쓴 꼴 |
| 녹지과 | 정원도시과 | (예시) 옛 부서 사업의 과반이 새 부서로 옮겨 감 |
