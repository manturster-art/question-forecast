# 화면 적용 원칙 — 구조는 Plane, 겉모양은 Vercel Geist (Task 4c, 2026-09-27 · Task 4e 보탬, 2026-09-28)

참고본: 구조 https://plane.so/ (업무 도구 화면), 겉모양 Vercel Geist 디자인 체계(https://vercel.com/geist). 그대로 옮기지 않고 아래처럼 조정했다.
색·글꼴 값의 정본은 `site/style.css` 의 `:root` 변수다.

## 구조

- **시작 화면(가운데)**: 큰 제목(도구 한 줄 소개) · 한 줄 설명 · **큰 부서 검색창**(자리 글 「우리 부서 이름을 입력하세요 (예: 주택과, 옛 이름도 됩니다)」, 폰(≤ 640px)은 「부서 이름 (예: 주택과)」 — 전체 문장은 aria-label, 치는 대로 아래 목록, ↑↓·Enter, 옛 이름 일치 표시) · **실·국 바로가기 칩**(가나다순, 순위 아님) · 작은 글씨 세 단계 안내와 「공개자료만 · 인터넷 없이 열림」. 배경은 「예보」 메시 그라데이션. 폰에서는 검색창이 폭 가득. 처음 열면 포커스가 이 검색창에 있다.
- **홈**: 왼쪽 위 도구 이름(「질문 예보」)이 홈 링크, 머리 줄 왼쪽에 「⌂ 처음으로」 단추. 홈으로 가면 주소에서 `dept`·`silguk`·`tab` 을 지우고(`fs`·`theme` 는 남김) 시작 화면으로, 포커스는 큰 검색창.
- **머리 줄 도구(오른쪽)**: 글자 크기 `가−` `가` `가+`(5단계 90·100·112·125·140%, 가운데 = 기본 100%, 단축키 `Alt` + `+`/`-`/`0`) · 테마 단추(누를 때마다 자동(시스템) → 라이트 → 다크, 아이콘 반달·해·달과 aria-label 로 지금 상태와 다음 상태를 알림) · 검색(`Ctrl+K`). 글자 크기·테마가 바뀌면 화면 낭독기용 알림(aria-live)으로 「글자 크기 125%」「화면 테마 다크」를 읽는다. **둘 다 저장하지 않는다**(저장소 0건 원칙) — 주소 `&fs=125`·`&theme=dark` 에만 남아 그 주소를 다시 열면 복원된다.
- **글자 크기 구현**: 스타일의 모든 길이를 rem 으로 적고(1·2px 선만 px), `html` 의 글자 크기 변수 `--fs` 를 바꾼다 — 간격·표·카드·아이콘·예산 막대 여백이 함께 커진다. 140% 에서도 1280px·375px 모두 가로 넘침 없음(캡처로 확인).
- **왼쪽 사이드바**: 도구 이름 → 부서 검색 단추(`Ctrl+K`·`/` 로도 열림) → 실·국 → 부서 나무 목록. 실·국마다 현행 부서만 두고, 지금 조직도에 없는 부서는 맨 아래 「옛 부서」 묶음. 「여러 부서 공통」「미상」은 목록에 없다. 현행 부서가 없는 「기타 (소속 미확인)」 실·국은 「옛 부서」 묶음 아래 머리로 두어(누르면 실·국 합산) 계속 열 수 있다. 실·국 이름을 누르면 실·국 합산, 화살표는 펼치기·접기. 이름은 가나다순(순위 아님).
- **빠른 검색**: 가운데 뜨는 상자. 부서·실·국·옛 이름을 찾고(줄 순서는 이름이 똑같은 부서 → 이름이 검색어로 시작 → 이름에 들어 있음 → 실·국·옛 이름으로 맞은 부서 → 실·국 합산; 순위가 아니라 맞춤 정도라 「주택」+Enter 는 주택과. 시작 화면 검색창도 같음), 옛 이름으로 맞으면 「옛 이름 「…」 일치」를 보인다. ↑↓ 고르기, Enter 열기, Esc 닫기.
- **본문 머리**: 머리말(`DEPARTMENT`/`OFFICE`) + 이름 + 소속, 그 아래 탭 **요약 · 지적 · 되풀이 · 약속 · 예산 · 자료 범위 · 프롬프트**. 건수 뱃지는 지적(건)·되풀이(줄기)·약속(건)·예산(세출 자료가 있는 해 수)·자료 범위(결과보고서 수). 요약·프롬프트는 셀 것이 없어 뱃지를 달지 않았다. 자료 범위에 불일치·0건·선언 없음 문서가 하나라도 있으면 그 뱃지를 빨간 점·빨간 글자로 바꾼다. 탭은 주소 `?dept=…&tab=…` 에 반영되고, ←→·Home·End 로 옮긴다.
- **요약 탭**(한 장 요약·인쇄용): 카드 4개(누르면 해당 탭) + 되풀이 상위 3줄기 + 최근 지적 6건 + 예산 막대 작은 판.
- **지적 탭**: 한 줄 = 이행 상태 아이콘 · `F2025-도시건설-025`(고정폭) · 제목 · (되풀이·상태 칩) · 위원회 칩 · 연도 · 원문. 묶기는 **이행 상태별**(미첨부 → 미조치 → 장기검토 → 추진중 → 계속추진 → 완료; 첨부·확인 뒤 줄이 칸을 옮김) ↔ **연도별**. 처리결과 첨부 칸은 이 탭 머리.
- **오른쪽 상세 패널**: 지적 줄을 누르면(↑↓·Enter) 요지·되풀이 사슬(같은 줄기 다른 해, 누르면 그 건으로 이동)·반영한 조치·원문 링크·「이 건 답변서 초안」. Esc·닫기로 닫고 포커스는 누른 줄로 돌아간다. 데스크톱에서는 목록 위에 겹쳐 뜨는 비모달 대화상자(role=dialog, 제목으로 이름 붙임)라 옆 줄을 바로 눌러 넘겨 볼 수 있고, 폰에서는 모달 시트(뒤 본문·목록 inert, Tab 이 패널 안에서만 돈다)다.
- **포커스 유지**: 화면을 다시 그려도 포커스를 잃지 않는다 — 탭·요약 카드는 새로 고른 탭 단추, 나무 목록은 같은 단추, 부서 고르기(검색·폰 서랍)·프롬프트는 본문 제목이나 프롬프트 탭, 「확인한 것 반영」은 첨부 칸의 결과 알림으로 옮긴다(자체 시험 「키보드 포커스」 단계).
- **폰(≤ 640px)**: 사이드바는 왼쪽 위 메뉴 단추로 여는 서랍, 탭은 가로 스크롤, 상세는 전체 화면 시트. 가로 넘침 없음(자체 시험이 확인).

## 겉모양

- 바탕 `#fafafa`, 카드 `#ffffff` + 1px 선 `#ebebeb`, 제목 `#171717`, 본문 `#4d4d4d`, 설명 글 `#5c5c5c`(`#666` 보다 어둡게). `#8f8f8f` 는 입력 자리표시·비활성 막대에만 쓴다.
- 그림자는 떠 있는 것(빠른 검색·상세 패널·폰 서랍)에만 아주 옅은 한 단.
- 색은 아래 「색 체계」대로 역할별로 고정해 쓴다. 포커스 테두리는 `#0070f3`.
- **조정 1**: 추정·경고 글자는 참고본 `#ab570a` 가 `#ffefcf` 띠 위에서 4.51:1 로 기준에 겨우 닿아, 한 단 어두운 `#9a4d06`(5.38:1)을 썼다.
- **조정 2**: 링크 글자는 `#0070f3` 이 `#fafafa` 위에서 4.36:1 로 모자라 `#0761d1`(참고본 link-deep)을 쓰고, `#0070f3` 은 포커스 테두리(글자 아님)에만 쓴다.
- 장식은 메시 그라데이션 하나(청록→파랑→보라, 투명도 0.09~0.16) — 본문 머리와 시작 화면에만.
- 글꼴: Geist·Geist Mono 가변 글꼴(SIL OFL 1.1, npm `geist` 1.7.2 에서 받음, `site/fonts/OFL.txt`)을 라틴·숫자·기호만 남긴 woff2 부분집합(17.5KB + 12.8KB)으로 CSS 안에 base64 인라인. 한글은 `Pretendard → Malgun Gothic → Apple SD Gothic Neo` 폴백. 카드 값·금액·연도·지적 번호·작은 머리말은 Geist Mono. 제목 무게 600, 자간 -0.02em(카드 큰 숫자만 -0.04em).
- 작은 머리말: `SUMMARY`·`FINDINGS`·`RECURRING`·`PROMISES — ESTIMATED`·`BUDGET`·`SOURCES`·`PROMPT`·`ATTACH` + 한글 제목.
- 단추: 주 행동(행감 대비·업무보고 대비·답변서 초안·처리결과 첨부·확인한 것 반영·이 건 답변서 초안)은 검은 알약, 나머지(내려받기·다시 조립·닫기·복사·이 파일 닫기)는 6px 단추. 한 줄 묶음 안에서는 섞지 않는다(첨부 칸은 알약 줄과 내려받기 줄을 나눔). 복사는 프롬프트 상자 안 6px 묶음이라 6px 검은 단추.
- 입력: 흰 바탕·가는 선·6px, 포커스는 파랑 2px.
- 다크 모드: 바탕 `#0a0a0a`, 카드 `#111`, 선 `#262626`, 글자 `#ededed`, 본문·설명 `#a1a1a1`.

## 색 체계 (Task 4e, 사용자 요청 2026-09-28 — 참고본의 단색 원칙보다 우선)

참고본(Vercel Geist)은 거의 단색이지만, 사용자 요청으로 **분류마다 고정 색**을 둔다. 값은 `site/style.css` 의 토큰(`--c-find`·`--c-rec`·`--c-prom`·`--c-exec`, `--ok`·`--warn`·`--err`)이 정본이다.

- **분류색**: 행감 지적 = 파랑, 되풀이 지적 = 장미(붉은), 답변 속 약속 = 보라, 집행률·예산 집행 = 청록. 쓰는 곳: 요약 카드의 숫자와 카드 왼쪽 띠, 해당 탭의 건수 배지, 칸 머리말(`FINDINGS`·`RECURRING`·`PROMISES`·`BUDGET`), 지적 번호, 「되풀이」 표시와 연도 사슬·되풀이 카드 띠·예산 그래프의 되풀이 점, 약속 카드 앞줄 띠와 날짜, 예산 막대의 집행분.
- **의미색(내용 강조)**: 이행 상태 완료 = 초록 · 추진중(계속추진) = 주황 · 미조치·장기검토 = 빨강(같은 느낌표 아이콘) · 미첨부 = 회색. 「추정 — 확인 필요」 = 주황 띠, 불일치·0건·선언 없음 = 빨강, 원문 링크 = 파랑 밑줄, 집행률 100% 초과 = 주황(숫자표 칸에 「초과」 글자와 설명 한 줄).
- **넓은 면은 칠하지 않는다**: 숫자·배지·표시·가는 띠(3px)에만 쓴다. 배지 바탕은 같은 색의 아주 옅은 판.
- **색만으로 뜻을 전하지 않는다**: 카드에는 이름(「행감 지적」 등), 배지는 탭 이름 옆, 되풀이는 「되풀이」 글자, 이행 상태는 아이콘 모양(점선 원·반원·체크·느낌표)과 글자, 초과는 「초과」 글자가 늘 함께 있다.
- **대비**: 글자로 쓰이는 색은 4.5:1 이상, 표시·띠는 3:1 이상. 아래 표는 카드 바탕 기준이며, 고른 줄·표 머리(`#ededed`/`#f2f2f2`, 다크 `#1c1c1c`/`#232323`)에서도 밝게 4.63(초록) 이상, 어둡게 5.84(빨강) 이상이다. 추진중 아이콘은 참고본 주황 점(`#d27d10`, 3.14 — 표 머리 위에서 3:1 미만)을 쓰지 않고 글자색 `#9a4d06` 을 쓴다.
