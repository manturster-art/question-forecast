# 다른 의회·지자체에서 쓰는 법 (표준화 1단계)

이 도구는 처음 적용한 의회의 공개자료로 만들었지만, 지자체마다 다른 값은
**`config/region.json` 한 곳**에 모았습니다. 코드(`dcc/`·`site/`·`prompts/`·`run.py`)에는
특정 지자체 전용 주소나 이름이 남아 있지 않습니다(`tests/test_region.py` 가 저장소를 훑어 지킵니다).
이 템플릿의 `config/` 는 가상 지자체 **「가나시」**(구 「가람구」·「나래구」)의 예시 값이고, 주소는 쓰이지 않는
`example.invalid` 입니다. 아래는 지금 코드로 되는 것과, 앞으로 하려는 것을 나눠 적었습니다.

## 먼저 견본 자료로 돌려 보기

`examples/sample/site_data.json` 은 「가나시」의 **지어낸** 행감 지적 33건·되풀이 4줄기·시정질문 약속 7건·
6개년 세출입니다(실제 기관·사람과 관계없음). 받기 없이 두 화면을 바로 굽습니다.

```bash
python run.py --site-only --sample      # out/부서점검표.html · out/의원점검표.html (+ 자체 시험판 둘)
python tools/make_sample.py             # 견본을 고쳤을 때 다시 만들기(tools/make_sample.py 안의 표를 고침)
```

견본은 `config/` 의 가나시 예시 설정과 짝이 맞습니다. 자기 지자체 설정으로 바꾼 뒤에는 견본 대신
`python run.py` 로 실제 공개자료를 받아 굽습니다.

## 지금 되는 것

`config/region.json` 에 든 값과 쓰이는 곳입니다.

| 칸 | 뜻 | 쓰는 곳 |
|---|---|---|
| `지자체명` · `약칭` · `의회명` | 예시 값 「가나시」「가나」「가나시의회」 | 화면 출처 문구, 프롬프트 [역할] 문구(굽는 때 `{{지자체}}` 자리를 채움), 기관 이름 앞 지자체명 떼기, 시정질문 낱말 거르기 |
| `의회.base` 와 경로들 | 의회 누리집 주소, 행감 목록·답변요지서 목록·뷰어·파일 조회·현직/역대 의원 쪽 경로 | 원문 수집(`dcc/council_site.py`), 누출 검사용 공개 명단(`dcc/names_public.py`), 화면에서 원문 링크를 걸어도 되는 주소 판정 |
| `세출.시누리집` | 시 누리집 「사업 및 예산정보」 엑셀 주소(`{year}` 자리) | 세출 수집(`dcc/expenditure.py`) |
| `시장소개` | 시장 프로필 쪽 주소 | 누출 검사용 공개 명단 |
| `구` | 일반구 이름과 구별 동 이름 앞말 | 부서 이름 맞추기(「가람구 행정지원과」), 동 → 구 판정 |

구가 없는 시·군은 `구` 를 빈 칸(`{}`)으로 두면 구 관련 규칙이 아무것에도 걸리지 않습니다.
`dcc/` 주석에 남은 「가람」「나래」는 규칙을 설명하는 예시일 뿐이고, 코드가 쓰는 값은 모두 `region.json` 에서 옵니다.
부서 규칙의 정규식은 실행을 시작할 때 한 번 만들므로, 실행 중에 `region.json` 을 고쳤다면 다시 실행합니다.

`region.json` 을 또 다른 가짜 지자체(「마바시」)로 바꿔 끼우면 수집 주소·화면 지자체명·프롬프트 문구가
모두 따라 바뀌는 것을 시험(`tests/test_region.py`)으로 확인합니다. 처음 적용한 의회에서는 값을 `region.json` 으로
옮기기 전과 뒤의 산출(`out/site_data.json`)이 바이트 단위로 같음을 확인했습니다.

## 다른 의회가 적용하는 순서

**① `config/region.json` 채우기.** 위 표의 값을 그 지자체 것으로 바꿉니다. 함께 바꿔야 하는
지역 자료 파일이 셋 있습니다.

- `config/행정기구.json` — 그 지자체의 「행정기구 및 공무원 정원 조례」·시행규칙에서 실·국과 부서를 옮긴 표.
  키마다 화면의 실·국 묶음이 된다: `실국`(실·국 → 부서), `부시장 직속`(부시장 밑 담당관 목록 — 옛 이름 `보좌기관` 도 읽음),
  `소속기관`(사업소·보건소 등), `구`(구청·구 부서·동), `출자출연기관`. 키 이름이 곧 화면에 보이는 묶음 이름이다
- `config/별칭.json` — 결과보고서에 줄여 적힌 부서 이름 → 정식 이름
- (선택) `data/세출_지방재정365.json` — 시 누리집 세출 자료가 늦게 갱신된 해를 메우는 지방재정365 값.
  꼴은 `[{"year": 2024, "acct": "일반회계", "project": "사업명", "budget": 원, "spent": 원}, …]`. 템플릿에는 없고, 없으면 보충 없이 돕니다

**② 누리집 게시판 짜임이 다르면 `dcc/council_site.py` 한 파일을 고칩니다.** 이 파일이
의회 게시판 어댑터입니다. 목록 표에서 연도·위원회·원문 번호를 뽑는 `parse_inspection_list`·
`parse_qna_list` 와, 뷰어 주소를 실제 PDF 주소로 바꾸는 `resolve_file` 이 게시판마다 다를 수
있는 곳입니다. 함수 이름과 돌려주는 꼴(`year`·`com`·`kind`·`uid` 등)을 그대로 두면 뒤 단계는
손대지 않아도 됩니다. 의원 명단 쪽 짜임이 다르면 `dcc/names_public.py` 의 이름 뽑는 꼴도 봅니다.

**③ 누리집이 없거나 막혀 있으면 규격 폴더로 넣습니다 — 설계만 있고 아직 구현하지 않았습니다.**
`input/결과보고서/`·`input/답변요지서/` 에 PDF 를 넣으면 수집 단계를 건너뛰고 그 파일을 읽는
방식입니다. 파일 이름에 연도·위원회(답변요지서는 회기·날짜)를 적는 규칙을 함께 정하려 합니다.
**지금 코드에는 이 입력 경로가 없습니다.**

## 의원용 페이지 (`out/의원점검표.html`)

집행부용(`부서점검표.html`)과 같은 자료로 굽는 두 번째 HTML 입니다. 상임위를 고르면 소관 부서가
「물을 거리」(조치 안 됨·되풀이·약속(추정)·집행 이상 — 가중치 없이 건수만) 많은 순으로 나옵니다.
지자체마다 다른 값은 아래 세 파일에 있습니다. 코드는 고치지 않습니다.

**`config/council.json`**

| 키 | 뜻 | 지금 값 |
|---|---|---|
| `exec_low` · `exec_high` | 최근 마감 연도 집행률이 `exec_low`% 미만이거나 `exec_high`% 초과이면 「집행 이상」 1건 | 60 · 100 |
| `dong_group` | 동 행정복지센터·구 동행정복지센터·구청 본체를 상임위 대신 넣을 묶음 이름. 키를 빼면 묶음이 없어지고 동·구청도 아래 규칙 2~5 로 갑니다 | 「구청·동 행정복지센터」 |
| `overrides` | `{부서 이름: [상임위, …]}` — 규칙보다 먼저 그대로 배정 | 두 구 민원봉사과 → 기획행정·도시교통 |
| `weather` | 날씨 그림 구간 `[{max, icon}, …, {icon}]`. 물을 거리 합계가 `max` 이하이면 그 날씨, 마지막 칸은 그보다 많은 것 모두. `icon` 은 「맑음」「구름 조금」「흐림」「비」 중에서(그림 모양이 정해져 있음). 평가가 아니라 건수 구간이며 화면에 범례가 함께 나옵니다 | 0 · 4 · 9 · 그 이상 |

**`config/상임위_변천.json`** — 결과보고서에 적힌 위원회 약칭·옛 이름 → 지금 상임위 이름.
예: `"총무경제": "기획행정위원회"`. 상임위가 개편되면 옛 이름을 여기에 더합니다. 지적의 위원회를 지금 이름으로
합쳐 셀 때(아래 규칙 4) 씁니다. 여기에 없는 약칭의 지적은 규칙 4 에서 세지 않습니다.

**`config/행정기구.json` 의 「상임위」 표** — `{상임위 이름: [실·국 또는 부서 이름, …]}`. 의회 회의규칙·
위원회 조례의 「소관」 조항을 옮깁니다. 보통은 실·국 이름을 적고, 한 실·국이 두 상임위로 나뉘면 부서 이름을
적습니다(예: 환경국 부서 일부는 도시교통, 일부는 복지환경). 소관이 사무국뿐인 상임위(의회운영위원회 → 의회사무처)도
표에 둡니다 — 표 순서가 화면의 상임위 순서입니다.

**배정 규칙**(`dcc/committees.py`, 앞의 것이 이깁니다)

0. `overrides` 에 있으면 그대로.
1. `dong_group` 이 있으면 현행 동(「○○동」「○○2동」 — 앞말은 `region.json` 「구」)·구 동행정복지센터·구청 본체는 그 묶음으로. 지적이 있어도 그렇습니다. 구 실·국 전체를 묶지 않는 것은 구 건설과·복지과까지 끌려오기 때문입니다.
2. 「상임위」 표에 **부서 이름 자체**가 있으면 그 상임위만(여럿이면 모두).
3. 이름이 없으면 그 부서의 **실·국**이 있는 상임위(여럿이면 모두).
4. 표에 없으면 그 부서 지적이 **가장 많은** 상임위(`상임위_변천.json` 으로 지금 이름으로 합쳐 셈). 두 구 공통 지적은 빼고 세며, 공통 지적뿐일 때만 그것을 씁니다. 수가 같으면 최근 연도가 있는 상임위, 그것도 같으면 모두.
5. 그래도 없으면 「소관 미확인」(`site_data.json` 의 `unassigned`, 의원용 시작 화면 맨 아래 목록).

**다른 의회가 바꿀 것.** ① 「상임위」 표를 그 의회 소관 조항대로 새로 씁니다. ② `상임위_변천.json` 에 그 의회
결과보고서에 나오는 위원회 표기를 모두 적습니다(`python run.py --offline` 뒤 「소관 미확인」이 많으면 여기부터 봅니다).
③ 구가 없는 시·군은 `dong_group` 을 빼거나 그대로 두어도 됩니다(`region.json` 「구」가 비면 걸리는 부서가 없음).
④ `overrides` 는 비우고(`{}`) 필요할 때만 씁니다. ⑤ 집행률 기준·날씨 구간은 의회가 정한 값으로 바꿉니다.
바꾼 뒤에는 `python run.py --offline`(자료층을 다시 만듦) → `python run.py --site-only` 로 다시 굽습니다.

## AI 에이전트에게 맡기는 법

위 ①~③과 의원용 설정은 사람이 해도 되지만, AI 코딩 에이전트(예: Claude Code)를 이 저장소 폴더에서 열고
맡기면 빠릅니다. 에이전트는 코드를 읽고 고치고 시험을 돌릴 수 있지만, **어느 누리집의 어느 게시판이 맞는지는
사람이 알려 줘야 합니다.**

**사람이 먼저 준비할 것**

| 무엇 | 예 |
|---|---|
| 의회 누리집 주소와 게시판 경로 | 행정사무감사 결과보고서 목록 쪽, 시정질문 답변요지서 목록 쪽, 현직·역대 의원 명단 쪽(누출 검사용) |
| 시 세출 자료 주소 | 시 누리집 「사업 및 예산정보」 엑셀 받는 주소(연도가 들어가는 자리) |
| 행정기구 조례 이름 | 「○○시 행정기구 설치 조례」·「… 시행규칙」 — 국가법령정보센터 자치법규에서 찾을 수 있는 정식 이름과 시행일 |
| 상임위 소관 | 위원회 조례·회의규칙의 소관 조항(상임위 → 실·국·부서), 최근 상임위 개편 이력 |
| 구·동 유무 | 일반구가 있으면 구 이름과 구마다 동 이름 앞말 |

**복사해 붙일 요청 글**

```text
이 저장소는 지방의회 행정사무감사 결과보고서·시정질문 답변요지서·시 세출 자료(모두 공개자료)로
부서용·의원용 오프라인 HTML 을 만드는 도구다. docs/표준화.md 를 먼저 읽고, 아래 지자체에 맞게 적용해 달라.

- 지자체: ○○시 / 의회: ○○시의회
- 의회 누리집: https://… (행감 결과보고서 목록: …, 답변요지서 목록: …, 의원 명단: …)
- 시 세출 자료 주소: https://…{year}…
- 행정기구 조례: 「○○시 행정기구 설치 조례」(시행 20○○-○○-○○)와 시행규칙
- 상임위 소관: (조항 내용을 붙여 넣음)
- 구·동: (없음 / 구 이름과 동 앞말)

할 일:
1. config/region.json 을 위 값으로 채운다.
2. config/행정기구.json(실·국·부서와 「상임위」 표), config/상임위_변천.json, config/council.json 을 새로 쓴다.
   config/별칭.json 은 비우고 결과보고서를 읽은 뒤 줄여 적힌 부서 이름만 더한다.
3. 게시판 짜임이 다르면 dcc/council_site.py(목록 읽기·원본 PDF 주소 찾기)만 고친다. 함수 이름과 돌려주는 꼴은 그대로 둔다.
4. python run.py 로 자료를 받고 굽는다. 「확인할 것」의 선언·파싱 건수 차이를 보고, 파서를 보탤 곳이 있으면 고친다.
5. docs/표준화.md 의 「적용 뒤 확인표」를 모두 채워 보고한다.

지킬 것:
- 공개자료만 쓴다. 내부 문서·비공개 처리결과·개인 파일은 저장소에 넣지 않는다.
- 사람 이름을 코드·설정·문서·시험 견본에 적지 않는다. 시험 견본에는 가짜 이름만 쓴다. 누출 검사를 끄거나 느슨하게 하지 않는다.
- 시험을 지우거나 약하게 고쳐서 통과시키지 않는다. python -m pytest -q 와 node --test "tests/js/*.test.js" 가 모두 통과해야 한다.
- 웹 요청은 dcc/http.py 로만 하고, 인증서 검증을 끄지 않는다.
- 어디에도 올리거나 배포하지 않는다(git push·공개 게시 금지). 끝나면 바꾼 파일 목록과 확인표만 보고한다.
```

**에이전트가 하면 안 되는 것**(요청 글의 「지킬 것」과 같음): 사람 이름 넣기, 비공개자료 쓰기, 누출 검사·시험을
끄거나 약하게 하기, 사람 승인 없이 올리기·배포하기. 결과는 아래 확인표로 사람이 다시 봅니다.

## 적용 뒤 확인표

| # | 확인 | 어떻게 |
|---|---|---|
| 1 | 선언 건수 = 파싱 건수 | `python run.py` 끝의 「확인할 것」 목록이 비었는지, 부서 화면 「자료 범위」 탭의 출처 표에서 문서마다 선언·파싱이 같은지. 다르면 파서를 보태거나 까닭을 적어 둡니다 |
| 2 | 이름 누출 없음 | 굽기 때 자동 누출 검사(걸리면 HTML 을 쓰지 않음)가 통과했는지, `python -m pytest -q tests/test_repo_no_real_names.py` 가 통과(건너뜀 아님)했는지 |
| 3 | 두 자체 시험 통과 | `python -m pytest -q tests/test_site_selftest.py tests/test_council_selftest.py` — Edge 헤드리스가 두 시험판을 열어 돌립니다(Windows 에서는 PowerShell 에서 실행) |
| 4 | 전체 시험 통과 | `python -m pytest -q` 와 `node --test "tests/js/*.test.js"` |
| 5 | 두 HTML 을 직접 열어 봄 | `out/부서점검표.html`(부서 하나 골라 탭·첨부·프롬프트), `out/의원점검표.html`(상임위 카드 → 부서 → 질문 후보·미리 보기) |
| 6 | 상임위 배정 미확인 목록 | 의원용 시작 화면 맨 아래 「소관 미확인」(또는 `out/site_data.json` 의 `unassigned`)에 **현행 부서**가 없는지. 있으면 「상임위」 표나 `상임위_변천.json` 을 고칩니다. 옛 부서만 남는 것은 괜찮습니다 |

## 전국 공통 원천 활용 계획

지자체마다 누리집이 달라도 전국이 같은 꼴로 내는 공개 원천이 있습니다. 앞으로 정식
표준화 스펙에서 아래를 기본 원천으로 삼고, 지자체 누리집은 보충으로 돌리려 합니다.

| 원천 | 지금 | 계획 |
|---|---|---|
| 지방재정365(세출) | 따로 받아 둔 파일(`data/세출_지방재정365.json`, 선택)을 보충용으로만 씀 | 지자체 코드만 넣으면 받아 오는 수집기 — 시 누리집 없이도 예산 추이가 서게 |
| 자치법규 「행정기구 및 공무원 정원 조례」(국가법령정보센터 오픈API) | 사람이 옮긴 `config/행정기구.json` 을 씀(파일 머리에 근거 조례·시행일자 기록) | 조례 이름으로 조회해 실·국·부서 표를 만드는 변환기 |
| CLIK 지방의회 회의록 오픈API(국회도서관) | 쓰지 않음 | 의회 누리집 게시판 짜임과 무관하게 회의록·시정질문을 받는 보조 원천 |

위 「계획」 칸은 아직 코드가 없습니다.

## 제약

- **결과보고서·답변요지서 서식은 의회마다 다릅니다.** 지적 번호 매김, 부서 꼬리표(`< 부서 >`),
  총괄 표 꼴이 처음 적용한 의회 문서에 맞춰져 있습니다. 다른 의회 문서를 넣으면 파서가 일부 항목을 놓칠 수
  있습니다.
- 그 차이는 숨지 않고 드러납니다. `run.py` 는 문서마다 총괄 표의 **선언 건수와 실제로 읽은
  건수를 대조**해 「확인할 것」에 적고, 화면의 출처 표에도 둘을 나란히 보입니다. 새 의회에 처음
  적용할 때는 이 목록을 보고 파서 꼴을 보태면 됩니다.
- 부서 이름 규칙(구 접두 떼기, 「여러 부서 공통」 묶기)은 시·구·동 짜임을 전제로 합니다.
  도(광역) 의회는 짜임이 달라 따로 봐야 합니다.
